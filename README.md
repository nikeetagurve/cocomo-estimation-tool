# COCOMO Estimation Tool — Dark Edition

A Streamlit implementation of a classical COCOMO estimation calculator.

## UI
- Black main background
- Dark grey sidebar
- White text
- Warm beige and muted pink charts
- LoC is the default input unit
- Same Basic / Intermediate / Detailed / Comparison functionality

## Run

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Push `app.py` and `requirements.txt` to a GitHub repository, then deploy the
repository through Streamlit Community Cloud.
